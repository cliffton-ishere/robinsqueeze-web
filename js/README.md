# js/

`wallet.js` is a BUILD ARTIFACT — generated by `npm run build` from `src/`.
It is committed because the site deploys as pure static files with no build
step on Vercel. Edit `src/*.ts` and rebuild; never edit `wallet.js` by hand.

`wallet-boot.js` is hand-written and NOT generated. It is the <2KB lazy loader
that renders the allocation preview and Connect button, and dynamically imports
`wallet.js` only when someone reaches for a wallet.
